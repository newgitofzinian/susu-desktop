# Susu 2.3：桌面小房子

## 使用

运行项目中的 `溯溯.app`，或解压 `release/溯溯桌面版-2.3.zip` 后运行。菜单栏爪印和右键菜单始终保留。

小房子由深蓝屋顶、木质门框、暖窗和门灯组成，背景透明。拖动实体部分搬家；单击房子叫溯溯进屋拿垫，走到门旁展开并趴下。再次单击会起身收垫、叼回屋内。右键 →「小房子」可单独控制拿垫、收垫、出来走走、大小与显示。取垫休息约 14 秒，收垫回屋约 7.5 秒。途中要求收垫，会完成当前取垫流程后接着收回，避免丢失或重复垫子。

小房子位置、大小、是否显示会记住；启动时摆出房子，溯溯从自由活动状态开始。安静、隐藏与休眠会暂停房子中的动画。工作模式下房子受同一地盘约束并自动缩放。

## 桌面交互调整

- 喂食：桌面上出现可拖动的点心，拖到实际狐狸身上。
- 藏松果：透明桌面上出现三堆落叶，沿用原来的猜测与揭晓玩法。
- 近看：直接显示透明放大狐狸，耳尖轻划和尾纹顺序互动继续保留；菜单可开关静音。
- 围巾：菜单直接穿戴、保存或删除造型、导入或删除配饰、导出模板。
- 暗号、卡片、信件、手帐、照片、聊天：在狐狸或房子旁显示临时气泡、纸卡及编辑控件；不再进入三个分页主窗口。
- 任务报信和存档迁移继续保留。导入导出使用系统文件选择器。
- 「收起当前道具 / 气泡」关闭临时交互，保留房子和桌宠。

房子与透明道具的空白区域可点击穿透，不绘制面板背景、标题栏或桌面地板。文字编辑等临时气泡仍含必要的输入框和按钮。本次没有将所有旧的内部页面类删除，但日常菜单不再调用旧的分页窗口。

## 验收

原生 smoke test 检查透明无标题房子、取垫、趴卧、收回、长时间留屋、重新拿出、关闭后回桌面和透明角落点击穿透。另覆盖七个中途收垫时点，避免流程卡住或收好后再次自动拿出；桌面道具入口与点心数量也纳入检查。沿用提醒、工作地盘、边界、信件、任务、存档、配饰导入和耳尾互动回归。

实际 AppKit 绘制预览位于 `Previews/2.3/`。房子、垫子和趴卧姿态为新透明素材；走动使用既有慢走动画，展开、收起与趴下使用淡入淡出转场。本版仍为 2D，没有增加 3D/AR。休息姿态暂未叠加围巾。真实多显示器组合、长时间日用与真实云模型兼容性仍待进一步验证。

制作提示词见 `Art/2.3/prompts.md`，最终素材在 `Assets/home/`。基础玩法运行时无需生成服务。
