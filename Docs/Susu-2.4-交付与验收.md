# 桌面小窝的显示与毯子动作

## 使用规则

启动与自由活动时不显示房子。右键或菜单栏爪印 →「小房子 → 回窝拿毯子休息」才摆出小窝；进屋取毯、叼毯走出、铺开与趴卧期间保持显示。单击小窝或选择「收毯子回屋」，溯溯会收毯、叼回屋里放下，然后空嘴走出来；恢复自由活动时房子自动收起。

「结束休息，出来走走」可立即结束当前流程。房子大小改为 320、440、560，未设置时为 440；选择大小不会单独唤出小窝。旧版 houseShown 常驻偏好不再读取。房子位置与大小仍保留，隐藏、安静和休眠暂停动画，工作模式按所选地盘约束。

## 毯子动作

8 帧叼毯慢走中，狐狸与毯子为共同绘制的完整姿态，有嘴部咬住的毯角、褶皱、负重与交替步态。搬运时不再叠加单独的卷垫图片。

另有 6 个连贯姿态，依次表现叼着毯子、低头放下、前爪压毯、推开、折腿和趴下；收毯逆向播放同一组关键姿态。完整关键帧逐帧播放，不以两张完整姿态交叉淡入，以避免双头、双尾重影；移动使用起停缓动。趴卧使用最后一帧，与铺开的毯子保持一致。搬运、铺毯与趴卧姿态暂不叠加围巾。

## 验证范围

原生 smoke test 覆盖启动隐藏、调整大小不唤出、进屋、搬运、铺毯、趴卧、收毯、返回、空嘴走出与自动隐藏；并覆盖 7 个中途收毯时点和再次开始。检查整体动作帧的 alpha 与尺寸，继续运行工作地盘、喝水提醒、原有玩法与存档相关检查。实际绘制预览在 `Previews/2.4/`。

素材通过内置 imagegen 生成，提示词和提取脚本在 `Art/2.4/`，运行素材在 `Assets/home/carry/` 与 `Assets/home/blanket-action/`。基础玩法无需生成服务。本次仍为 2D 关键帧动画，未增加骨骼系统或 3D。

本机应用 `溯溯.app`；安装包 `release/溯溯桌面版-2.4.zip`。旧安装包继续保留。真实多屏组合与长时间日用仍需进一步反馈。
