# Susu 2.2 交付与验收

本版补齐需求文档中的 F06、F08、F09、F12、F14 的首版功能。版本 2.2，构建 9。

## F06 小窝家具布置

菜单栏爪印 →「生活工坊」→「小窝布置」。在预览中拖动睡垫、收藏架和灯，松手保存位置。「打开桌面小窝」显示可独立收起的小场景，「叫溯溯进窝」让狐狸从左侧走到睡垫并用闭眼伏身姿态休息。移动睡垫后再召回，落点随睡垫改变。

收起小窝后狐狸回到原桌面位置。工作模式中的桌面小窝会缩放并约束到当前地盘内，提醒卡片仍可正常出现。探险期间等待它归来后再召回。家具布局保存在存档，重启与迁移后保留。

## F08 换装工坊

可选湖绿、琥珀、莓红三条内置围巾，保存命名造型，例如「学习日」。预览显示待机、向右散步与向左散步，桌面狐狸同步穿戴。可删除造型、卸下围巾或删除导入包。

首版围巾覆盖待机与左右散步。跑步、伸懒腰、玩耍、近看反应使用各自原动作与表情图片。

「导出制作模板」生成一个新文件夹，包含 scarf.json、6 帧 idle 和 8 帧 walking。修改相应透明 PNG 后，用「导入配饰文件夹」装入。每帧为 192×208，与狐狸使用同一画布，向左散步由宿主同步镜像。素材在导入时复制进存档，原文件夹以后可以移动。

缺帧、越出文件夹的路径、错误尺寸与非透明边角会被拒绝，当前造型保留。素材包与造型随存档导出迁移。

## F09 合影与明信片

生活工坊 →「明信片」。选择森林绿、湖水蓝或暖色纸笺背景，选择待机、伸懒腰或玩耍，用滑块定格六个姿态之一。输入题字后点击刷新预览，再选择「导出 PNG」。

输出为 1200×720，包含所选背景、狐狸、日期与题字。图片从应用内素材生成。导出位置由用户选择。

## F12 模型聊天与指定记忆

菜单栏爪印 →「和溯溯聊天」。配置你选择的 OpenAI-compatible Chat Completions 服务的完整接口地址、模型名称和 API Key，再点「保存连接」。支持 HTTPS，以及本机回环 HTTP 服务。点击「发送」才请求服务。

对话会保留上下文。发送时携带最近最多 30 条历史消息与用户明确保存的记忆。选择某条消息并点击「记住选中消息」后，才加入长期记忆；下方列表支持查看完整记忆和删除。「新对话」清空会话历史、保留指定记忆。删除某条记忆后另开新对话，该记忆不再进入请求。

API Key 按服务源存入 macOS 钥匙串，界面支持单独删除。Key 不进入存档、导出文件或日志。更换设备后需重新配置凭据。接口地址、模型、对话与指定记忆保存在本地存档中。

请求可停止，关闭聊天窗口会取消请求。网络失败、服务错误、异常响应和过大回复会显示状态信息。跨地址重定向不会自动转发请求。真实服务的费用和能力取决于用户选择的模型服务。

已通过本地模拟服务的两轮对话、上下文、指定记忆删除、HTTP 失败和回复大小边界检查。尚未配置真实模型账号，真实服务与钥匙串凭据操作仍需用户配置后使用。

## F14 挠耳朵与尾尖暗号

生活工坊 →「近看溯溯」。按住并轻划耳尖，或点击挠耳按钮，显示对应侧耳贴近的反应。按从上到下的顺序触碰尾尖三颗琥珀纹样，触发眯眼微笑；点错顺序会重新开始。

耳朵与眯眼使用本版生成的独立表情素材。近看互动结束后回到原外观。静音默认开启，取消静音时使用本机合成的短提示叫声。

## 数据升级与完成范围

存档格式升级为 3，保留 2.0／2.1 的身份、口味、手帐、任务、暗号、探险、抽认卡与信件。读取旧格式时先保存对应版本的备份文件。新格式请使用 2.2 或后续兼容版本，旧版本恢复对应备份。

截至 2.2，需求文档 F01–F14 均有首版功能入口。3D 与 AR 保留为后续方向，专用动作、配饰美术、更多家具和更丰富的探险内容仍可继续完善。

## 验证与限制

- 原生页面、三件家具拖放与保存、睡垫移动后的进窝落点、收起返回。
- 围巾模板导出、合法包导入、缺帧拒绝、三种朝向预览与存档迁移。
- 明信片尺寸和 PNG 输出。
- 耳尾互动的正确与错误顺序，以及静音表情反应。
- 聊天的选中消息记忆、删除与新对话保留规则，以及模拟服务的两轮请求。
- 旧版存档迁移、备份、非法布局保护及新功能整体导入导出。
- 既有提醒、桌面边界、暗号、探险、抽认卡、信件与任务报信回归。

未完成多显示器真实硬件组合、长时间日用与真实云模型兼容性验证。

## 关于以后升级 3D

可以继续使用现有项目。行为、玩法状态、手帐、存档和提醒可以沿用；增加独立的 3D 显示层，使用相同的行为事件驱动模型。

模型、材质、骨骼、表情和三维动作需要制作或生成，并做绑定与调整。现有图片能提供角色外观和动作参考，单张正面图没有可靠的背面与完整几何信息。AR 在模型和行为接口稳定后再增加空间放置、跟踪与设备交互。
