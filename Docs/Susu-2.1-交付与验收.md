# Susu 2.1 交付与验收

本版接续 2.0，实现需求 F04、F07、F10、F11。版本 2.1，构建 8。

## 新玩法入口

点击菜单栏爪印，选择「新的共同经历 · 暗号 / 探险 / 抽认卡 / 信」。

### F04 教狐狸听暗号

在「教暗号」中填写名字，例如「收工啦」，选择两个动作并保存。第一版支持伸懒腰、玩耍两种既有动画的组合。输入已保存的文字暗号，再点「说出上面这句暗号」，狐狸依次播放两个动作。可从列表选择暗号修改顺序或删除，重启后保留。

安静、隐藏、屏幕休眠、探险或喝水卡片显示期间不会开始执行。拖动、隐藏、安静模式、屏幕休眠、任务报信和喝水卡片会中断已开始的动作串。触发另一动作时取消未播放的后续动作。

### F07 林间探险

在「林间探险」选择河岸或松林，一次旅程约一分钟。桌面狐狸暂时显示为可点击的「探险中」标记，主窗口及工作模式喝水计时继续运行。河岸归来收集鹅卵石，松林归来收集松果，同类收藏累积数量，每次归来记入手帐。

关闭应用后仍保存归期，重新打开会结算到期旅程。收藏数量、旅程清空和手帐以同一次原子存档写入，重复刷新不会再次获得发现物。本版路线结果固定，后续可扩展发现物和专用出行动画。

### F10 狐狸抽认卡

手工填写题面与答案，保存后可以抽卡、翻面、标记「记住了」或「再练」。优先抽待复习卡，同组按上次复习时间由早到晚安排，尽量避免立即重复；只剩一张待复习卡时会优先继续练它。全部记住后重新轮换全部卡片。

列表中可以编辑或删除卡片，删除结果跨次启动保留。编辑页用于修改题面和答案。「开始复习」进入独立练习页，先显示题面，翻面后显示答案，可随时返回编辑。

### F11 留给未来的一封信

写下内容与未来投递时间，交给溯溯。一次保管一封待投递的信，寄出前可选择它改内容、改期或取消。默认投递时间为一分钟后，便于首次体验。

到期后桌面出现信封标记，点击即可打开信箱，也可从菜单「查看未来的信」进入。选中未读信，点击「拆开这封信」才展示正文。已读信可以保留或删除。应用关闭期间到期，会在下次启动投递一次。

安静或隐藏期间不主动弹窗，未读状态保留。信件使用本地存档保存。

## 存档升级

沿用 ~/Library/Application Support/SusuDesktop/save.json，保留 2.0 的身份、口味、手帐及任务去重数据。首次读取 2.0 格式会先保留 save-2.0-backup.json，再升级到版本 2 格式。

2.1 导入导出包括暗号、卡片、信件、收藏和未结束的探险。旧 2.0 存档也可导入。存档范围校验失败时保留当前记录。2.1 格式请使用 2.1 或后续兼容版本打开，2.0 读取旧格式备份。

## 验证

数据检查覆盖旧格式迁移与备份、暗号更新删除和跨次启动、两条路线在模拟归期后结算且不重复、复习优先级和删除、定时信改期取消与跨次启动投递、拆阅保留和完整迁移。

原生检查覆盖四个页面的实际保存入口、暗号两步播放与中断、安静模式阻止开始，以及 2.0 的游戏、投喂、提醒、任务和移动回归。探险和投递的时间边界使用模拟时间验证，真实一分钟体验与长期日用仍可继续收集反馈。

本版使用现有狐狸动画与原生界面，未生成专用出行、睡觉或信件动作图片。F06 家具、F08 换装、F09 明信片、F12 模型聊天、F14 分区互动仍在后续候选中。
