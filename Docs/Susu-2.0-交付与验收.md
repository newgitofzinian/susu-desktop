# Susu 2.0 交付与验收

本版按桌面《产品核查与功能需求》的首批建议实现。当前版本 2.0，构建 7。

## 已交付

| 需求 | 2.0 入口与行为 |
| --- | --- |
| F01 藏松果 | 菜单「林间小屋」→「藏松果」。点击落叶堆藏松果，狐狸依次嗅探三堆，剩两个候选时给提示或让它随机选。揭晓显示真实藏处与选择结果。Esc 关闭小屋，喝水提醒打断游戏。 |
| F02 投喂与口味记忆 | 「投喂」拖点心到小屋里的狐狸，也可拖给桌面狐狸。投喂后播放已有玩耍帧作为接食回应，记录次数。累计三次后「双盘」解锁，先选次数较多的点心，同次数随机。可清除口味重新培养。 |
| F03 任务报信 | 「任务」复制命令，将末尾命令换成自己的测试。随应用提供本机编译的 susu 工具。等待时显示沙漏并暂停自动游走，成功显示绿叶，失败显示感叹号，取消显示返回标记。点击桌面结果标记可打开详情。 |
| F05 狐狸手帐 | 「手帐」记录首次收点心、首次找到松果和首次接收任务结果。可选记录、编辑批注与删除，首次记录删除后不会被重复生成。 |
| F13 存档迁移 | 「存档」导出与导入 JSON，保留身份编号、口味、手帐及首次事件记录。导入替换前有确认，坏文件保持原存档。现有桌面位置和 1.5 偏好继续使用原配置。 |

## 本版实现方式

小游戏在独立小屋窗口内进行，使用已有狐狸图片和原生绘制道具。接食、嗅探分别复用玩耍和伸懒腰图片。任务结果使用徽标。需求描述的专门接食、叼叶片和竖耳新绘制动画仍可继续制作。

F04 暗号、F06 家具布置、F07 探险、F08 换装、F09 明信片、F10 抽认卡、F11 定时信、F12 模型聊天、F14 分区互动为后续候选。本版未包含 3D 或 AR。

## 修复核查问题

- 用逻辑坐标累计小数位移，避免窗口取整导致向右慢走原地结束。小、中、大各验证左右 100 点真实窗口行程，终点误差不超过 2 点，高度误差不超过 1 点。
- 喝水预览仅提供关闭预览，保留正式计时。正式到期卡片继续支持确认与延后 5 分钟。
- 预览网格保留宠物隐藏状态。
- 原生边缘自检按两个坐标轴分别容许 1 点取整差，另外保留可见身体面积断言。

## 验证结果

- 原生应用自检通过，六个小屋页面已绘制并检查，支持三处藏物正确与错误结局。
- 原生应用执行真实 susu 命令，成功与失败结果进入桌宠徽标和手帐，重复完成事件不重复记账。
- 命令工具单独验证成功、失败、找不到命令、取消、并发拒绝和取消后再次启动。
- 存档测试验证重启保留口味、批注、删除和首次事件去重、身份迁移、坏文件不覆盖。
- 保留 1,836 个桌面边缘位置、432 个工作地盘位置、1,512 个水平路径采样与提醒计时测试。
- 食物拖放处理按完成投放才记账。真实鼠标拖动和长时间日用仍需用户体验反馈，多显示器实际硬件组合尚未验证。

## 使用与数据

打开项目中的「溯溯.app」，点菜单栏爪印，再选「林间小屋」。安装包保存在 release/溯溯桌面版-2.0.zip，之前版本继续保留。

成长存档在 ~/Library/Application Support/SusuDesktop/save.json。任务事件在同目录 tasks 中。原有偏好继续由 macOS UserDefaults 保存。升级首次运行建立一份新成长存档，不清除旧版的大小、位置、工作模式或提醒偏好。

任务页会给出可复制的完整命令路径。示例结构如下，实际路径随应用所在位置变化。

```sh
'/应用所在路径/溯溯.app/Contents/MacOS/susu' watch -- swift test
```

保留原命令的输入、输出和退出码；取消任务返回 130。一次交办一个任务，内核文件锁在进程退出后自动释放。
