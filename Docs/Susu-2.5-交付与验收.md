# 四季外观

右键或菜单栏爪印 →「造型与合影 → 季节外观」选择春、夏、秋、冬或原始外观。手动选择，不按日期自动切换。

| 季节 | 设计 |
| --- | --- |
| 春 | 奶白小花、鼠尾草绿叶与细亚麻胸带 |
| 夏 | 海蓝薄棉水手领、奶白双滚边与琥珀木扣 |
| 秋 | 栗棕小挎包、枫叶扣与斜挎帆布带 |
| 冬 | 莓红针织围巾、奶白罗纹收边 |

每季有六帧身体固定的摇尾待机与八帧左右慢走。服饰透视、褶皱、接触阴影与身体共同绘制，向左时整体镜像。内置外观不再绘制旧的几何围巾贴片。进出小窝的空嘴慢走与待机合影也使用所选外观。

跑步、伸懒腰、玩耍、叼毯、趴卧与近看互动仍使用已有专用素材，结束后恢复季节外观。旧的自制配饰包仍兼容原来的独立透明贴片格式。

## 保存与兼容

四季选择、命名造型随存档保存、导出和迁移。旧内置围巾标识保留并解析为冬季；第一次保存新的季节标识前，会创建 save-before-seasons-backup.json。旧程序不识别新增季节标识，回退时使用原备份。

## 验收

- 四季选择和命名造型的重启、导入导出，以及非法季节值保护。
- 旧围巾映射、首次季节选择的原样备份。
- 56 帧透明素材加载；原生待机、向右和向左绘制、透明区域点击与可见身体区域。
- 四季六帧待机身体像素变化均为 0，继续使用独立尾巴层。
- 原有桌面边界、工作地盘、喝水提醒和小窝流程回归。

素材与提示词在 Art/2.5，最终运行素材在 Assets/seasons，实际绘制预览在 Previews/2.5。使用内置 imagegen 生成；运行时无需生成服务。

本机应用为溯溯.app，安装包为 release/溯溯桌面版-2.5.zip，旧版安装包继续保留。真实多屏组合和长期日用仍需进一步反馈。
