# 溯溯桌面版 1.0

双击本目录中的 **溯溯.app** 即可打开。无需安装开发工具、登录账号或联网。

## 操作

| 操作 | 效果 |
| --- | --- |
| 单击溯溯 | 弹跳并回应一句话 |
| 拖动溯溯 | 移动到喜欢的位置，退出时记住位置 |
| 右键溯溯 | 打开操作菜单 |
| 点击菜单栏的爪印 | 即使溯溯隐藏，也能找到控制菜单 |
| 选择“散步一会儿” | 在当前位置向旁边走一小段，遇到屏幕边缘停下 |
| 开启“自动散步” | 每隔一段时间散步；默认关闭 |
| 开启“安静模式” | 停止动作、散步与对话气泡 |
| 选择“大小” | 切换小、中、大 |
| 选择“暂时隐藏” | 隐藏宠物，菜单栏入口保留 |
| 选择“回到主屏幕” | 显示宠物并放回主屏幕底部 |
| 选择“退出溯溯” | 完全退出 |

透明区域会将鼠标点击传给下方窗口。应用不会自动设置开机启动，也不申请摄像头、麦克风或辅助功能权限。

## 文件与后续升级

- `溯溯.app`：本机可直接运行的应用。
- `溯溯桌面版-1.0.zip`：已打包的应用备份。
- `Sources/main.swift`：窗口、互动、动画状态和菜单逻辑。
- `Assets/frames/idle`：6 帧呼吸与眨眼素材。
- `Assets/frames/running-right`：8 帧向右散步素材；向左通过逐帧镜像显示。
- `Previews`：动画预览、实际应用绘制的静态预览、素材边缘清理记录和验证记录。
- `build.sh`：重新编译与打包脚本；仅修改代码后重新打包时需要 Mac 的 Swift 命令行工具。

本版使用二维动画图片。三维模型、3D 渲染和 AR 尚未包含；后续可逐步接入，并保留现有的点击、拖动、菜单和行为设计。

## 验证范围

已在当前 Apple Silicon Mac 上编译、执行本机应用启动检查，验证素材加载、呼吸/眨眼及双向散步绘制、不透明区域鼠标命中、透明区域点击穿透判定。完整桌面拖动与多显示器交互仍需日常使用反馈。
